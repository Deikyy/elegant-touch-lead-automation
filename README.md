# 🛠️ Elegant Touch Interior – Lead Automation System

This project contains two complete automation workflows built in [n8n.io](https://n8n.io) for Elegant Touch Interior, an interior design company.

## 🎯 Problem

- Missed website inquiries
- No structured lead tracking
- Follow-ups were delayed
- Everything was handled manually

## ✅ Solution

1. **Lead Capture + Scoring Workflow**
   - Triggered by website form submission
   - Automatically scores leads into: HOT / WARM / COLD
   - Stores lead into Google Sheets CRM
   - Sends auto-follow-up reminder after 2 days

2. **HOT Lead Monitor Workflow**
   - Runs on schedule (hourly)
   - Checks Google Sheets CRM
   - Sends alert email to sales team if a new HOT lead is detected

## 🔧 Tools Used

- n8n.io (workflow engine)
- Google Sheets API
- Gmail API
- JavaScript Code Nodes
- (Optional: WhatsApp / Slack integration)


## 🧠 Outcome

The sales team now:
- Responds faster
- Never misses a qualified lead
- Saves time from manual follow-ups
